# AI Indian Store Sales Forecasting Dashboard

## 📊 Project Overview
This project is a Machine Learning-based **sales forecasting system** built for Indian retail data.  
It predicts future sales trends and provides interactive business insights using a Streamlit dashboard.

---

## 🚀 Features

- 📈 Sales Forecasting using Machine Learning
- Indian Retail Dataset Support
- 📊 Interactive Dashboard (Streamlit)
- 🎯 Real-time Predictions
- 📉 Trend Analysis (Monthly, Category, Region)
- 📥 Download Forecast Reports
- ⚡ Fast and Optimized Performance (Caching Enabled)

---

## 🧠 Tech Stack

- Python 🐍
- Pandas & NumPy
- Scikit-learn 🤖
- Plotly 📊
- Streamlit 🌐
- Joblib
